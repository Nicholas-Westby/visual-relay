# Improve Task Card Styles

In the list of tasks, the cards have some rough styles that could use some improvements.

For one, they all have square edges despite their being a rounded edge within that. We don't need the outer square edges.

We should also make sure that it's apparent that a card is both active and in progress. Right now, we represent those with blue and green. The combined style should do something like a blue rounded rectangle border on the outside of the existing green rounded rectangle/border.

and make sure you don't add the square corners; rounded cornders for all states (default, active, in progress, and combined active + in progress).
