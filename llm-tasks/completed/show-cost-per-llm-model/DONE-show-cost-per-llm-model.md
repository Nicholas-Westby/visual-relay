# Show Cost Per LLM Model

In "Settings", add a section to show the cost per LLM model. Make it collapsed by default (similar to sandbox paths).

The values should derive from the code so what is displayed cannot deviate from what the code says (i.e., a single source of truth).

For the models that have variable pricing depending on the time of day, show that per-time pricing. Make sure the times are in the user's local timezone.
