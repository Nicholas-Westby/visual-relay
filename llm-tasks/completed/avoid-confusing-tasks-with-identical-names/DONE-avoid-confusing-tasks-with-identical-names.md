# Avoid confusing tasks with identical names

I created the "speed-up-automated-tests" task from a template again. It then showed all stages complete. This was likely because a task with the same name was already completed. I've since deleted the duplicate and created a new one with a unique name as a workaround.

It should be possible to create tasks with the same name later on and not have it confused with a completed task.

Care should also be taken not to overwrite them. Up to you to decide how, but one idea would be to move completed tasks into a GUID subfolder on completion to avoid collisions.
